## はじめに

突然ですが、こんな気持ちになったことはありませんか？

- 「GitHub Copilot って気になるけど、ちゃんと使えるか不安…」
- 「コミュニティって、なんか発表レベルが高そうで怖い」
- 「学生だし、まだ何もできてないから場違いかも」
- 「最新のAIの動向を簡単に知りたい」

**それ、全部気にしなくて大丈夫です。**

この記事では、私が運営メンバーとして参加している **GitHub Copilot User Group Japan（通称：Gh-CUG / ジーカグ）** というコミュニティをご紹介します。

学生でも、初心者でも、「なんか面白そう」と思ったらとりあえず参加してほしい。そんなゆるふわコミュニティです。

## 📖 GitHub Copilot User Group Japan (Gh-CUG) とは？

**GitHub Copilot User Group Japan（Gh-CUG / ジーカグ）** は、「もっと世の中に GitHub Copilot を広げたい！」という熱い思いから生まれたユーザーコミュニティです。

ノンデベロッパーからエンジニアまで、みんなでワイワイ学び、楽しみながら知見を共有していく場を目指しています。

GitHub Copilot の便利な活用法はもちろん、開発手法・就活・個人開発・ハッカソン・日常の生産性向上まで、**Copilot に少しでも関係していればどんな話題でも大歓迎！**

「まず触ってみたい」「業務で使ってみた」「失敗したので誰かに相談したい」など、**温度感の違う話題を持ち寄れるコミュニティ**にしていきます。

🔗 **Connpass グループページ：** [GitHub Copilot User Group Japan](https://gh-cug.connpass.com/)

### 💡 私たちのモットー

> **「なんでもは知らない、しってることだけ」**

完璧な知見や、すごい実績である必要は全くありません。

初心者の方も萎縮せず、「とりあえず出してみる」「ちょっと話してみる」こと自体を全力で歓迎します。それぞれの「こんなんできた！」「ここがつまずいた！」を持ち寄り、全員でフラットに GitHub Copilot を楽しみましょう！

### 👥 こんな人におすすめ

- GitHub Copilot が気になっているけれど、まだ触り始めたばかりの人
- 日々の勉強や個人開発・ハッカソンの中で、もっと上手く使えないか試している人
- 発表してみたいけれど、いきなり大きな場は不安な人
- 同じテーマに関心のある仲間と、ゆるくつながりたい人
- 就活に向けてエンジニアコミュニティに顔を出してみたい学生

## 🤝 コミュニティのグランドルール

Gh-CUG では、以下のルールを大切にしています。

- **みんなで楽しく学び合う** ── 互いの知見をリスペクトし、讃え合いましょう
- **初心者にも優しく** ── 誰でも最初は初心者です
- **間違っていたら優しく教える** ── 強く責めるのではなく、助け合いましょう
- **わいわい試せる雰囲気を大切に** ── 正しさだけでなく、まず出してみる空気を大切に
- **参加者みんなで場を育てる** ── 運営だけが作るものではありません
