## はじめに

「Copilot Chatで長いやり取りをしていたのに、別のチャットを開いたら消えてしまった…」「昨日の会話を今日も続けたい」

そんな経験はありませんか？

**実は、VS Code の GitHub Copilot Chat には、過去のチャット会話を保存・再開できる「Chat Sessions（チャットセッション管理）」機能があります。**

この機能は VS Code **1.99（2025年3月）** の Unified Chat View 統合で本格的に導入され、その後のアップデートでさらに進化しました。この記事では、Chat Sessions 機能の基本的な使い方から応用テクニックまでを徹底解説します。

この記事を読むと、以下のことができるようになります：

- ✅ 過去のチャットセッションを検索・再開できる
- ✅ 複数のセッションを並列で管理できる
- ✅ 会話を「フォーク」して別方向に探索できる
- ✅ セッションをプロンプトテンプレートとして保存・再利用できる

## 前提条件

| 項目           | バージョン                                               |
| -------------- | -------------------------------------------------------- |
| VS Code        | 1.99 以降（推奨: 最新版）                                |
| GitHub Copilot | 有効なサブスクリプション（Free/Pro/Business/Enterprise） |

## Chat Sessions とは？

### チャットセッションの基本概念

**チャットセッション**とは、AIとの一連の会話のまとまりです。プロンプト・レスポンス・添付したコンテキストがすべてセッション単位で管理されます。

重要なポイントは以下のとおりです：

- **セッション間でコンテキストは引き継がれません**（各セッションは独立）
- セッションは**ローカルに自動保存**され、いつでも再開できます
- **複数のセッションを並列で実行**できます（例：片方で実装、もう片方でリサーチ）

:::note info
💡 **ポイント**: 「別チャットで会話を保持」とは、**別のセッションとして保存されている過去の会話を再開する**ことを指します。コンテキストが自動的に引き継がれるわけではなく、あくまでそのセッションの続きとして再開できます。
:::

### v1.99 以前との違い

VS Code 1.99 以前は、Copilot Chat と Copilot Edits が**別々のビュー**として独立していました。

| 変更前（〜v1.98）                | 変更後（v1.99〜）                          |
| -------------------------------- | ------------------------------------------ |
| Chat ビューと Edits ビューが分離 | **Unified Chat View** に統合               |
| セッション履歴が別管理           | 全モード（Ask/Edit/Agent）の履歴を一元管理 |
| Editsセッションは再開不可        | すべてのセッションを再開可能               |

## Sessions list の使い方

### Sessions list を表示する

Chat ビューの左側（または上部）に **Sessions list**（セッション一覧）が表示されます。

**表示モードは2種類あります：**

- **コンパクト表示（Compact）**: セッション一覧がChatビューに埋め込まれる。チャットビューが狭い場合のデフォルト
- **サイドバイサイド表示（Side-by-side）**: Chatビューを横に広げると自動的に切り替わる

右クリック → `Sessions Orientation` で表示方法を変更することもできます。

:::note info
💡 **非表示にしたい場合**: Chatビュー内を右クリック → `Show Sessions` のチェックを外す（または `chat.viewSessions.enabled` を `false` に設定）
:::

### 過去のセッションを再開する

1. Chat ビューで Sessions list を開く
2. 一覧から再開したいセッションをクリック
3. チャットが再開され、以前の会話が表示される

セッションは**時系列でグループ化**（今日・先週など）されており、**検索・フィルタ**も可能です。

### 新しいセッションを開始する

| 操作               | 方法                                      |
| ------------------ | ----------------------------------------- |
| 新規セッション開始 | Chat ビューの `+` ボタン、または `Ctrl+N` |
| サイドバーで開く   | `Chat: New Chat` コマンド                 |
| エディタタブで開く | `Chat: New Chat Editor` コマンド          |
| 別ウィンドウで開く | `Chat: New Chat Window` コマンド          |
| 最大化して開く     | Chat ビュータイトルバーの最大化ボタン     |

## 便利な管理機能

### ピン留め

重要なセッションはピン留めしておくと、一覧の上部に固定されます。

1. Sessions list でセッションにホバー
2. **ピンアイコン**をクリック

### アーカイブ

完了したセッションをアーカイブして一覧を整理できます。削除ではないのでいつでも復元可能。

1. Sessions list でセッションにホバー
2. **Archive** をクリック

アーカイブ済みセッションを見るには、フィルタオプションから `Archived` を選択します。

### 削除

```
セッションを右クリック → Delete
```

:::note alert
🚨 **注意**: 削除は**元に戻せません**。単に非表示にしたい場合はアーカイブを使いましょう。
:::

## 応用テクニック

### セッションのフォーク（分岐）

長い会話の途中から「別のアプローチを試してみたい」という場面に最適です。フォークすると、元のセッションを保持したまま新しいセッションで別方向に探索できます。

**フォークの方法は2つあります：**

**① セッション全体をフォーク**

```
チャット入力欄に /fork と入力して Enter
```

**② チェックポイントからフォーク**

1. 会話の中の任意のリクエストにホバー
2. **Fork Conversation** ボタンをクリック
3. そのチェックポイントまでの会話を引き継いだ新セッションが開く

:::note info
💡 **フォークの活用例**

- 実装方針Aと方針Bを並行して探索する
- バグ修正の途中で「別の修正方法も試してみたい」場合
- 長い設計議論から「この方向で進める」と決めた時点以降を別セッションに切り出す
  :::

### セッションのエクスポート

セッションをJSONファイルとして保存できます。チームへの共有や記録として活用できます。

1. 保存したいセッションを Chat ビューで開く
2. コマンドパレット（`Ctrl+Shift+P`）から `Chat: Export Chat...` を実行
3. 保存先を選択

### プロンプトテンプレートとして保存

```
チャット入力欄に /savePrompt と入力して Enter
```

これで、現在のセッションが `.prompt.md` ファイルとして保存されます。汎用的なタスクテンプレートとして、別プロジェクトでも再利用できます。

### Markdown でコピー

チャット内を右クリックすると、以下のオプションが表示されます：

| オプション            | 内容                                 |
| --------------------- | ------------------------------------ |
| `Copy`                | 選択したメッセージ1件をコピー        |
| `Copy All`            | セッション全体をMarkdown形式でコピー |
| `Copy Final Response` | 最後のレスポンスのみをコピー         |

## 通知設定

別ウィンドウで作業中でも、チャットの応答やAIからの確認依頼を**OS通知**で受け取れます。

```json
// settings.json での設定例
{
  "chat.notifyWindowOnResponseReceived": "windowNotFocused",
  "chat.notifyWindowOnConfirmation": "windowNotFocused"
}
```

| 値                               | 動作                                |
| -------------------------------- | ----------------------------------- |
| `off`                            | 通知しない                          |
| `windowNotFocused`（デフォルト） | VS Codeにフォーカスがない時のみ通知 |
| `always`                         | 常に通知                            |

## よくある誤解・注意点

### ❌「セッションを再開すると前の文脈が自動的に引き継がれる」

**→ 正しくは**: セッションを再開すると**そのセッション内の会話履歴**は引き継がれますが、**別セッションとのコンテキスト共有はありません**。各セッションのコンテキストウィンドウは独立しています。

### ❌「クラウドに同期されるので別PCでも見られる」

**→ 正しくは**: チャット履歴は**ローカル保存のみ**です。Settings Sync の対象外です。別PCで同じ会話を参照したい場合は、JSONエクスポートを使ってください。

### ❌「セッション間でAIが記憶を持ち続ける」

**→ 正しくは**: AIはセッションをまたいで自動的に記憶しません。永続的なコンテキストが必要な場合は、後述の**Custom Instructions**や**Prompt files**を使いましょう。

## 「永続コンテキスト」が欲しい場合の代替手段

| 機能                                                         | 用途                                               | 永続性       | クラウド同期             |
| ------------------------------------------------------------ | -------------------------------------------------- | ------------ | ------------------------ |
| **Chat Sessions**                                            | 過去の会話を再開する                               | ローカル保存 | ❌                       |
| **Custom Instructions**（`.github/copilot-instructions.md`） | コーディング規約・ルールをすべてのリクエストに適用 | ファイル     | ✅                       |
| **Prompt files**（`.prompt.md`）                             | 再利用可能なチャットテンプレート                   | ファイル     | ✅（ユーザープロンプト） |
| **Instructions files**（`.instructions.md`）                 | 特定ファイルタイプへの自動適用ルール               | ファイル     | ✅                       |

:::note info
💡 **おすすめの使い分け**

- **毎回同じルールを適用したい** → Custom Instructions
- **特定のタスクを何度も繰り返す** → Prompt files（`.prompt.md`）
- **過去のやり取りを参照したい** → Chat Sessions の再開
  :::

## まとめ

| やりたいこと               | 方法                                    |
| -------------------------- | --------------------------------------- |
| 過去のチャットを再開したい | Sessions list からセッションを選択      |
| 整理したい                 | アーカイブ or ピン留め                  |
| 別方向を試したい           | `/fork` または Fork Conversation ボタン |
| 保存・共有したい           | `Chat: Export Chat...`（JSON）          |
| テンプレート化したい       | `/savePrompt`（`.prompt.md`）           |
| 永続的なルールを持たせたい | Custom Instructions / Prompt files      |

VS Code 1.99 から統合された Chat Sessions 機能により、Copilot Chat は単なる「使い捨ての質問ツール」から、**プロジェクトをまたいで継続的に活用できる開発パートナー**へと進化しました。ぜひ Sessions list を活用して、より快適な AI 開発体験を手に入れてください！
