# Gh-CUG 学校掲示用ポスター 画像生成プロンプト

## Google Gemini（Nano Banana）用

---

## ✅ 使い方

1. Google Gemini を開く（https://gemini.google.com）
2. 「画像を生成して」と伝えた後、下記プロンプトを貼り付ける
3. 手持ちのイメージ画像を添付して「このイメージを参考にして」と追記する
4. 気に入ったものが出たら保存 → 印刷（A3 or A4 推奨）

---

## 🖼️ プロンプト（日本語版）

```
大学の掲示板に貼る告知ポスターを生成してください。

【デザインコンセプト】
- ターゲット：大学生・情報系学生・エンジニア志望の学生
- 雰囲気：ゆるふわ・親しみやすい・初心者歓迎・テック系
- スタイル：モダンでポップ、でも知的。フラットデザイン
- カラー：ダークネイビーまたは黒をベースに、エメラルドグリーンとホワイトのアクセント（GitHub カラー）

【掲載する情報】
- コミュニティ名：GitHub Copilot User Group Japan（Gh-CUG / ジーカグ）
- キャッチコピー：「なんでもは知らない、しってることだけ」
- サブコピー：学生・初心者大歓迎！最新AIの活用法をゆるく学べるコミュニティ
- 第1回イベント：ゆるよな Gh-CUG #01
- 開催日時：2026年5月26日（火）21:00〜 オンライン
- 参加方法：connpass で「Gh-CUG」と検索
- ハッシュタグ：#GhCUG
- QR コード：右下にダミーの QR コードのデザインを配置

【アイコン・イラスト要素】
- GitHub の Octocat（タコみたいなキャラ）またはロボット・AI をイメージしたかわいいキャラクター
- パソコン・コードのアイコン
- 吹き出しで「就活に使える！」「ハッカソンに強くなる！」「登壇できる！」などのポイントをポップに表示

【レイアウト】
- A3 縦長（297mm × 420mm）
- 上部にキャッチコピーと大きなタイトル
- 中段にイベント情報と参加メリット
- 下部に QR コードと connpass URL（https://gh-cug.connpass.com/）

添付した画像のイメージ・雰囲気を参考にしてください。
```

## 💡 追加指示（生成後に調整したい場合）

| やりたいこと         | 追加プロンプト                                             |
| -------------------- | ---------------------------------------------------------- |
| もっとポップにしたい | 「もっとカラフルでポップなデザインにして」                 |
| シンプルにしたい     | 「余白を多くしてミニマルなデザインにして」                 |
| キャラを変えたい     | 「ロボットではなくタコのキャラクター（Octocat 風）にして」 |
| 文字を大きくしたい   | 「キャッチコピーの文字をもっと大きく目立たせて」           |
| 配色を変えたい       | 「背景を白にして、アクセントカラーを青緑にして」           |
