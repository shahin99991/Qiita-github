## 事前準備

- [ ] VS Code を **1.142 以降**（デスクトップ版）に更新（`Help > About` で確認）
- [ ] `chat.canvases.enabled` を ON（`img-02` で撮影済みの状態）
- [ ] **設定を変えたあとは新しいセッションを作る**（既存チャットには反映されない）
- [ ] 新しいセッションの **ハーネスが Copilot** になっていることを確認（Local / Claude / Codex では動かない）
- [ ] 撮影用に空のワークスペース、または記事リポジトリ（`Qiita-github`）を開く
- [ ] 画面は **ダークテーマ・ウィンドウ幅は広め**（Canvas とチャットが横並びで読める幅）
- [ ] 個人情報・API キー・トークンが映り込まないか確認（`.env` を開かない）

## デモ手順とスクショのタイミング

### デモ1: `/create-canvas` で Canvas を作る → `demo-01`

1. 新しい Copilot ハーネスのセッションを開く
2. チャットに次のプロンプトを貼って送信する（`/create-canvas` の入力画面は `img-03` で撮影済み）

   ```text
   /create-canvas 記事執筆用のカンバン Canvas を作って。
   列は「ネタ」「執筆中」「レビュー」「公開済み」。
   人はカードの追加とドラッグでの移動ができる。
   エージェントは get_board / add_card / move_card を呼べるようにして。
   ```

3. エージェントが拡張機能を作成し、Canvas が開くまで待つ
   - 権限の確認ダイアログが出たら許可する（このダイアログも撮っておくと、記事の補足に使える）
4. 📸 **撮影タイミング: Canvas がチャットの横に開いた直後**
   - チャットと Canvas の **両方が1枚に収まる** ように撮る
   - 4列（ネタ / 執筆中 / レビュー / 公開済み）が見えている状態がベスト
   - 保存名: `demo-01-canvas-created.png`

メモしておくこと（記事の `<!-- TODO -->` に反映）:

- 生成までの所要時間（目安でOK）
- 生成された見た目の第一印象
- 作成先のフォルダ（`.github/extensions/...` か `~/.copilot/extensions/...` か。作成時に選択肢が出たらその文言）

### デモ2: エージェントにカードを追加してもらう → `demo-02`

1. チャットに送信する

   ```text
   この記事を公開するまでに必要なタスクを、ボードに5枚追加して。
   ```

2. エージェントのツール呼び出し（`add_card` など）が走り、Canvas 上にカードが増える
3. 📸 **撮影タイミング: カードが5枚並んだ直後**
   - 可能なら、チャット側に **ツール呼び出しのログ（`add_card` 等）が映っている** 状態で撮る
   - 保存名: `demo-02-agent-adds-cards.png`

### デモ3: 自分の手でカードをドラッグする → `demo-03`

1. Canvas 上のカードを1枚、**「ネタ」→「執筆中」** にドラッグ＆ドロップする
2. 📸 **撮影タイミング: ドロップした直後**（カードが「執筆中」列に入った状態）
   - ドラッグ中の瞬間が撮れるなら、そちらのほうが「手で触ってる感」が出るので、2枚撮って良いほうを採用
   - 保存名: `demo-03-drag-card.png`

### デモ4: エージェントが手動の変更を読み取る → `demo-04`

**ここが記事の一番のキモ。** プロンプトで教えていないのに、手で動かした結果をエージェントが知っているかを見せる。

1. デモ3の直後、**何も説明せず** にチャットに送信する

   ```text
   いまボードで「執筆中」にあるカードを教えて。
   ```

2. エージェントが `get_board` を呼び、先ほどドラッグしたカードを含めて答える
3. 📸 **撮影タイミング: エージェントの回答が出そろった直後**
   - Canvas（「執筆中」にカードがある状態）とチャットの回答が **同時に見える** ように撮る
   - 保存名: `demo-04-agent-reads-board.png`

メモしておくこと:

- 正しく読み取れたか（読み取れなかった場合は、その挙動も記事に正直に書く）
- 応答までの体感スピード

### デモ5: Canvas を閉じて、メニューから開き直す → `demo-05`

1. Canvas のタブを閉じる
2. Chat ビューの **New Chat (+)** をクリックしてメニューを開く
3. 📸 **撮影タイミング: メニューに「Canvas」サブメニューが出ている状態**
   - サブメニューを展開して、作成した Canvas の名前が見えている状態にする
   - 保存名: `demo-05-open-canvas-menu.png`
4. Canvas をクリックして開き直せることを確認する（ボードの状態が残っているかもメモ）

> ※ Canvas サブメニューは、**サポート対象の Copilot ハーネスのセッションで最初のメッセージを送ったあと**に表示されます。出ない場合はまずここを確認してください。

## うまく動かないとき

| 症状                         | 確認すること                                                                  |
| ---------------------------- | ----------------------------------------------------------------------------- |
| `/create-canvas` が出ない    | VS Code が 1.142 以降か / 新しいセッションか / ハーネスが Copilot か          |
| Canvas が開かない            | `chat.canvases.enabled` が ON か（設定変更後に新規セッションを作ったか）      |
| New Chat (+) に Canvas がない | 最初のメッセージを送ったか / Canvas 拡張機能が作成・インストールされているか  |
| Local / Claude / Codex で試した | Canvases は Copilot ハーネスのローカルセッション専用（現時点）              |
| リモート・Web で試した       | デスクトップ版のローカルセッション以外は非対応                                |
