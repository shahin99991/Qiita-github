## 撮影前のチェック

- [ ] 個人情報・API キー・トークン・**コミットメッセージなど社内情報**が映り込んでいない（`.env` を開かない、通知・ブラウザタブにも注意）
- [ ] 実行結果の依頼は、**ファイルを変更しない読み取り系**にする（無人で動くので安全のため）
- [ ] 画面はダークテーマ・ウィンドウ幅は広め
- [ ] 撮影後、`images/` に ASCII のファイル名で置く（日本語・スペースを含むファイル名は URL で壊れやすい）
- [ ] push して `main` に入るまで raw URL は 404 になる。公開前に push する

## 画像だけ差し替えたいとき

記事内の URL は変えずに、**同じファイル名で上書きして push** すれば差し替わります。
Qiita 側は画像をキャッシュすることがあるので、反映されないときは、ファイル名にバージョンを付ける（例: `demo-12-scheduled-result-v2.png`）か、少し時間を置いてから確認してください。
