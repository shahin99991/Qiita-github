# 画像生成プロンプト集（MSAのなり方 記事用）

- 記事: [article-qiita.md](./article-qiita.md)
- 保存先: `TobeaMSA/Images/`
- 今回は GitHub Copilot の画像生成（`image_generation`）で作成しました

## 使い方

1. 使いたい画像の節にあるコードボックスを、右上のコピーボタンで丸ごとコピーする
2. 画像生成ツールに貼り付け、サイズは 16:9 に近い横長（1536x1024）を指定する
3. 描画された日本語に誤字がないか、目視で確認する
4. 指定のファイル名で `TobeaMSA/Images/` に保存し、記事公開前に GitHub へ push する

## うまくいかないとき

### 文字が誤字になる

```text
直前の画像と同じ構図で作り直してください。画像内の日本語は、指定した文言を1文字も変えずに描画してください。指定していない文字、英単語、記号は追加しないでください。
```

### ロゴや商標マークが混ざる

```text
直前の画像と同じ構図で作り直してください。企業ロゴ、商標マーク、ブランドのアイコンは描かず、単純な図形のアイコンだけを使ってください。
```

### 文字が小さくて読みにくい

```text
直前の画像と同じ構図で作り直してください。見出しは今の1.3倍、説明文は1.5倍の大きさにして、スマホで見ても読める太さにしてください。余白は少し減らして構いません。
```

### レイアウトが指定と違う

```text
直前の画像のレイアウトを、次の構成に直してください。横長16:9、上部に大見出し、その下に指定した数のカードを同じ大きさで横一列に並べ、カード同士を矢印でつなぐ。カードの数と順番は指定どおりにしてください。
```
